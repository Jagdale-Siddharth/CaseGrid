# AICTE PS 26264 Video Demo Script

> **Problem Statement 26264**: Integrated Dashboard for Monitoring and Tracking Institution-Related Complaint Cases Across AICTE Bureaus/Cells  
> **Target Video Duration**: 7–9 Minutes  
> **Key Presenter Persona**: Confident, clear, professional engineering pitch.

---

## Pre-Recording Checklist & Screen Setup

1. **Split-Screen or Picture-in-Picture Setup**:
   - Left side / Main window: Browser on `http://localhost:5173` (Light theme recommended for video clarity).
   - Right side / Inset: Mobile phone screen mirrored (via scrcpy, Vysor, QuickTime, or Expo Go recording).
   - Secondary Browser Tab: API Swagger Docs on `http://localhost:8000/docs`.
2. **Accounts to remember** (password for all: `Demo@1234`):
   - **Supervisor**: `supervisor` (All bureaus, reviews routing & overlaps, can reassign).
   - **Regulation / Technical Bureau Officer**: `kulkarni` (Scoped to own bureau only).
   - **Management**: `management` (Read-only high-level views & report exports).
3. **Seeded State**:
   - Ensure backend is running (`uvicorn app.main:app --reload --reload-dir app`).
   - Ensure frontend is running (`npm run dev`).
   - Ensure Expo is running in `mobile/` (`npx expo start -c --tunnel`).
